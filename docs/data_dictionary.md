# Data Dictionary — Brazil Election Insights

This data dictionary documents the exact 45 columns present in official TSE *Boletim de Urna* (BU) files (`bweb_*.csv`) for the 2026 general elections, verified by direct inspection of all 56 CSV files in `data/bronze/tse/2026/`.

## 1. File Specification & Ingestion Format

- **Format**: Semicolon-delimited CSV (`;`)
- **Quoting**: Strings enclosed in double quotes (`"`)
- **Encoding**: `ISO-8859-1` / `CP1252` (Latin-1)
- **Granularity**: One record per candidate / vote option, per office, per polling section.
- **Null / Sentinel Values**:
  - `#NULO#`: Represents non-applicable string values (e.g. party name for blank/null votes, or absence of aggregated sections).
  - `-1` or `-3`: Numeric sentinel for missing or not-applicable values (e.g. party number for blank/null votes, electoral board indices).

## 3. Key Mathematical and Consistency Invariants

For each polling section (`SG_UF`, `CD_MUNICIPIO`, `NR_ZONA`, `NR_SECAO`) and for each office (`CD_CARGO_PERGUNTA`):

1. **Turnout Identity**:
   $$\text{QT\_APTOS} = \text{QT\_COMPARECIMENTO} + \text{QT\_ABSTENCOES}$$

2. **Vote Sum Identity (Single-Choice Offices)**:
   For majoritarian races (`Presidente`, `Governador`, single-seat `Senador`):
   $$\sum \text{QT\_VOTOS} = \text{QT\_COMPARECIMENTO}$$

3. **Valid Votes Identity**:
   $$\text{Votos Válidos} = \sum_{\text{Nominal}} \text{QT\_VOTOS} + \sum_{\text{Legenda}} \text{QT\_VOTOS}$$
   $$\text{QT\_COMPARECIMENTO} = \text{Votos Válidos} + \sum_{\text{Branco}} \text{QT\_VOTOS} + \sum_{\text{Nulo}} \text{QT\_VOTOS}$$
